# 应用图标

需要在此目录放置应用图标文件：

| 目录 | 尺寸 |
|------|------|
| mipmap-mdpi | 48x48 dp (48x48 px) |
| mipmap-hdpi | 48x48 dp (72x72 px) |
| mipmap-xhdpi | 48x48 dp (96x96 px) |
| mipmap-xxhdpi | 48x48 dp (144x144 px) |
| mipmap-xxxhdpi | 48x48 dp (192x192 px) |

图标文件名：
- ic_launcher.png
- ic_launcher_round.png (圆形图标)

建议使用简单的图标设计，可使用：
- Android Studio -> Image Asset
- 在线工具：https://easyappicon.com/
