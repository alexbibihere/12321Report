# 12321投诉助手 - 应用设计文档

**日期**: 2025-01-16
**类型**: Android原生应用
**复杂度**: 极简工具

---

## 1. 项目概述

开发一个Android极简工具应用，帮助用户快速投诉骚扰电话到12321受理中心。

### 1.1 核心价值
- 一键投诉：复制号码后点击快捷方式即可发起投诉
- 无需学习：自动跳转投诉页面
- 体积小巧：纯原生实现，约2-3MB

### 1.2 使用场景
用户从通话记录中复制骚扰电话号码后，点击桌面快捷方式，应用自动提取号码并跳转到12321投诉页面。

---

## 2. 功能需求

### 2.1 核心功能
| 功能 | 描述 |
|------|------|
| 剪贴板读取 | 读取系统剪贴板内容 |
| 号码提取 | 使用正则表达式从文本中提取11位手机号 |
| 链接构造 | 将号码嵌入12321投诉链接 |
| 应用跳转 | 调用微信或浏览器打开投诉页面 |

### 2.2 用户流程
```
1. 用户在通话记录中复制骚扰号码
2. 用户点击桌面"12321投诉"快捷方式
3. 应用启动（后台运行）
4. 读取剪贴板 → 提取号码 → 构造链接
5. 调用微信/浏览器打开投诉页面
6. 应用自动退出
```

### 2.3 错误处理
| 场景 | 处理方式 |
|------|----------|
| 剪贴板为空 | Toast提示"未检测到剪贴板内容" |
| 未找到号码 | Toast提示"未检测到有效手机号码" |
| 未安装微信 | Toast提示"正在使用浏览器打开..." |
| 其他异常 | Toast提示"打开失败，请重试" |

## 4. 详细设计

### 4.1 号码提取正则
```kotlin
// 支持11位手机号，可选+86前缀，可包含分隔符
val phonePattern = Regex(
    """(?:\+?86)?[-\s]*(1[3-9]\d)[-.\s]*(\d{4})[-.\s]*(\d{4})"""
)
```

### 4.2 投诉链接格式
```
基础URL: https://wechat.12321.cn/harass

号码传递方式：
- 如果支持URL参数：https://wechat.12321.cn/harass?phone=13812345678
- 如果不支持参数：跳转后用户需在页面中手动粘贴号码
```

**注**：根据实际测试结果确定最佳实现方式。如果链接不支持号码参数，可将号码自动复制到剪贴板，方便用户在投诉页面粘贴。

### 4.3 跳转策略
```kotlin
// 策略1: 尝试调用微信
val wechatIntent = Intent().apply {
    setPackage("com.tencent.mm")
    action = Intent.ACTION_VIEW
    data = Uri.parse(complaintUrl)
}

// 策略2: 降级到系统浏览器
val browserIntent = Intent(Intent.ACTION_VIEW, Uri.parse(complaintUrl))
```

### 4.4 快捷方式配置
在 `AndroidManifest.xml` 中声明：
- `<action android:name="android.intent.action.MAIN" />`
- `<category android:name="android.intent.category.LAUNCHER" />`

用户可长按应用图标创建桌面快捷方式。

## 5. 权限与隐私

### 5.1 权限需求
**无需特殊权限**

| 权限 | 是否需要 | 原因 |
|------|----------|------|
| READ_CLIPBOARD | 否 | Android 10+ 应用内读取剪贴板无需权限 |
| INTERNET | 否 | 通过外部应用打开链接 |
| 其他 | 否 | 功能极简，无需其他权限 |

### 5.2 隐私保护
- 应用不存储任何用户数据
- 应用不联网
- 应用不请求位置、通讯录等敏感权限
- 处理完成后立即退出，不留后台进程
